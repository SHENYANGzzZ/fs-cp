# Obsidian 同步 Skill

## 概述

这个 Skill 帮助您将 Trae 中的工作记录自动同步到 Obsidian 知识库，实现开发工作流与知识管理的无缝衔接。

## 核心功能

### 1. 对话记录同步
- 自动整理对话内容
- 提取关键决策和行动项
- 按项目组织存储

### 2. 开发日志同步
- 记录代码提交
- 记录功能开发进展
- 记录问题修复过程

### 3. 任务进度同步
- 更新任务完成状态
- 记录待办事项
- 追踪项目里程碑

## 配置要求

### Obsidian 库路径

在使用前，需要确认 Obsidian 库的路径。默认路径：
```
/Users/shenyang/Documents/Obsidian-Vault
```

### 目录结构

按项目组织，建议结构：
```
Obsidian-Vault/
├── 01-Projects/
│   └── [项目名]/
│       ├── README.md          # 项目概述
│       ├── dev-logs/          # 开发日志
│       │   └── YYYY-MM-DD.md
│       ├── conversations/     # 对话记录
│       │   └── YYYY-MM/
│       │       └── YYYY-MM-DD-[主题].md
│       └── tasks.md           # 任务进度
└── 05-Daily/
    └── YYYY-MM-DD.md          # 每日笔记
```

## 使用方法

### 手动触发

直接说以下任意短语触发同步：
- "保存到 Obsidian"
- "同步到 Obsidian"
- "记录到笔记"
- "保存对话"
- "记录开发日志"

### 自动触发

以下情况会自动建议同步：
1. 完成重要功能开发
2. 解决复杂问题
3. 做出重要决策
4. 对话结束前（如果内容有价值）

### 同步命令

```
/obsidian-sync [类型] [选项]

类型：
  conversation  - 同步对话记录
  dev-log       - 同步开发日志
  task          - 同步任务进度
  all           - 同步所有内容

选项：
  --project [项目名]  - 指定项目名称
  --auto             - 自动模式（不询问确认）
```

## 工作流程

### 同步对话记录

1. 分析当前对话内容
2. 提取关键信息：
   - 问题/需求
   - 解决方案
   - 代码变更
   - 决策要点
   - 后续行动
3. 确定项目名称
4. 生成 Markdown 文件
5. 保存到对应目录

### 同步开发日志

1. 分析本次会话的开发活动
2. 提取信息：
   - 完成的功能
   - 修改的文件
   - 遇到的问题
   - 技术决策
3. 追加或创建日志文件
4. 更新项目 README（如有重大变更）

### 同步任务进度

1. 读取当前任务状态
2. 更新完成状态
3. 添加新任务
4. 记录阻塞问题
5. 更新里程碑状态

## 智能特性

### 自动识别项目

根据以下信息自动识别当前项目：
1. 工作目录名称
2. package.json 中的项目名
3. Git 仓库名称
4. 用户明确指定

### 内容智能提取

- 自动识别代码块并高亮
- 自动提取文件路径
- 自动识别决策点
- 自动生成行动项

### 链接建议

根据内容自动建议相关笔记链接：
- 搜索关键词匹配
- 项目相关笔记
- 技术主题笔记

## 注意事项

1. **权限限制**：由于 Trae 的安全限制，文件会先保存到项目目录，需要手动复制到 Obsidian 库

2. **文件命名**：
   - 对话记录：`YYYY-MM-DD-[主题].md`
   - 开发日志：`YYYY-MM-DD.md`
   - 任务进度：`tasks.md`

3. **编码格式**：使用 UTF-8 编码，确保中文兼容

4. **链接格式**：使用 Obsidian 的 `[[]]` 双向链接语法

## 与其他工具集成

```bash
git log --oneline --since="today"
```

### 项目配置

读取项目配置文件获取项目信息：
- `package.json` - Node.js 项目
- `Cargo.toml` - Rust 项目
- `pyproject.toml` - Python 项目

## 故障排除

### 问题：找不到 Obsidian 库

**解决方案**：确认库路径，或手动指定：
```
同步到 Obsidian，路径是 /path/to/your/vault
```

### 问题：文件编码错误

**解决方案**：确保使用 UTF-8 编码，避免特殊字符。

### 问题：链接无法跳转

**解决方案**：确认笔记文件已复制到 Obsidian 库，并刷新 Obsidian。
